# Artist Links

A free, responsive Linktree-style landing page for an artist, built with plain HTML and CSS. No framework, subscription, database, or build step required.

## Make it yours

1. Open `index.html` and replace **Your Name**, the bio, and the sample link URLs with your own details.
2. Change the flower emoji in the avatar or replace it with an image you own.
3. Edit the featured links and social links to match the accounts you want to share.
4. Commit your changes to the `main` branch.

## Publish for free with GitHub Pages

1. In this repository, open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select `main` and the `/ (root)` folder, then save.
4. GitHub will publish the page at `https://theducksquacking-hub.github.io/art/` after the Pages deployment finishes.

GitHub Pages hosting is free for public repositories. A custom domain is optional and may have separate domain-registration costs.
